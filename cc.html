How to reproduce this

node tools/cc-fleet-telemetry.mjs <coordinator log> --out data/cc-fleet-telemetry.json
node tools/export-cc-fleet.mjs --telemetry data/cc-fleet-telemetry.json --out data/cc-fleet-metrics.json
node bin/fleet-burn.js data/cc-fleet-metrics.json --cap-reads-per-day 50000
node tools/build-cc-dashboard.mjs

The first step keeps counters and timestamps and drops everything else, so the log never has to be published. The second emits the same fleet-burn/metrics@1 document the CLI already reads — no second format. The last one runs the real library so this page and the CLI cannot disagree.
